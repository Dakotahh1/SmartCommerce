# SmartCommerce

> Plataforma web, PWA y Android que recomienda y compara productos de supermercado de forma **personalizada y explicable**, combinando calidad, precio, disponibilidad y preferencias con datos abiertos de **Open Food Facts**.

Proyecto de la asignatura **Ingeniería Web Avanzada** — Ingeniería Civil Informática.
